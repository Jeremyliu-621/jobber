Paper Cuts - UC Berkeley 1st Place Overall ($5,000) and Best UI/UX. A game
engine that converts user sketches into playable game assets by training an
SDXL diffusion model on AWS Trainium and developing a cascading CNN/VLM
recognition pipeline with Redis HNSW vector memory.

- Trained "Moose", a LoRA-tuned model that understands drawings and codes them
  with game mechanics in under 500 ms.

Technologies: Python, PyTorch, FastAPI, Redis, AWS Trainium, JavaScript.

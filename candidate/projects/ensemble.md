Ensemble - Hack the 6ix Top 5 Overall. An orchestra conducting system that
synchronizes audience phones via WebSockets, using a QNX-based Raspberry Pi,
Arduino R4 wand, and a TinyML model to translate physical gestures into live
wand control.

- Fine-tuned and deployed a Qwen LoRA model on a Fireworks H200 using SFT and
  GRPO over classical music theory, generating musical bars in real time with
  453 ms latency.

Technologies: Python, QNX Raspberry Pi, Qwen LoRA.
